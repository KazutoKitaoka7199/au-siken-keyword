# ことばの積み重ね

応用情報技術者試験の用語を、スマートフォンで少しずつ学ぶ個人用 Web アプリです。ログインは不要です。

## できること

- 四択・○×・用語入力・選択式穴埋め・ドラッグによる組み合わせ問題。
- 分野・出題形式の選択、全体ランダム出題、問題数を固定しない継続学習。
- 毎問の正解・解説表示と、各用語の出典リンク。
- 回答履歴・正答率の保存、苦手な用語の優先出題・集中復習。
- 用語・読み・英語名による検索と分野絞り込み。
- 英字の大小・全半角・前後空白を正規化した入力採点。データに登録された英語名・別名にも対応。

## 開発

Node.js 24 以上と npm を使います。既存のチェックアウトで作業してください。クラウドタスクはすでに隔離されているため、ユーザーが指定しない限り Git worktree は不要です。

```sh
npm ci
npm run dev
```

開発サーバーの既定ポートは 5173 です。アプリは静的ファイルだけで動作し、データベースや API キーは不要です。フォントも同梱しており、画面表示のための外部 CDN は使いません。

```sh
npm run check       # 全用語の照合・採点と保存のテスト・型チェック・本番ビルド
npm run test:e2e    # パソコンとスマホのブラウザ操作テスト
npm run preview     # ビルド済みアプリの確認
```

ブラウザテストには npm 同梱の Chromium を利用します。ブラウザの別途ダウンロードは不要です。既存の Chromium を使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` に実行ファイルのパスを指定できます。タッチドラッグ・5 形式の採点・解説・次の問題・再読み込み後の記録・データ読み込み失敗時の再試行を検証します。

## 用語データ

参照元は [応用情報技術者試験ドットコムの用語集](https://www.ap-siken.com/keyword/)（シラバス 7.2）です。全 23 分野・96 小分類の 5,488 掲載分を取り込み、重複をまとめた **4,921 語**を収録しています。複数分野に属する用語は、すべての所属分野を保持します。

- `public/data/terms.json`: 用語・登録英語名・短い学習用説明・所属分野・出典リンク。
- `data/source-inventory.json`: 参照元の各小分類の掲載数・用語 ID 一覧・取得時の本文ハッシュ。
- `npm run data:verify`: 全掲載分と収録用語の対応、必須項目、分野を照合します。

元サイトは説明に生成 AI を使用していると明記しています。本アプリの短い説明も参照元に基づき、人手で全件校正したものではありません。各解説のリンクから元の用語集を確認できます。

データを更新する場合:

```sh
npm run data:sync                 # 保存済みの取得キャッシュを利用
npm run data:sync -- --refresh    # 参照元から再取得
npm run data:verify
```

更新時だけ `www.ap-siken.com` への HTTPS 接続が必要です。リクエストは順番に実行し、間隔を空けます。掲載数が一致しない場合は更新を止め、既存データを維持します。取得キャッシュは `.cache/glossary/` に保存され、Git の対象外です。アプリの学習中に参照元サイトへの自動リクエストは行いません。

## 記録と採点

履歴と設定は、この端末・ブラウザの localStorage だけに保存します。端末間同期はありません。ブラウザのデータ削除で学習記録も消えます。保存容量不足などで保存に失敗した場合は画面に通知し、破損した記録を自動上書きしません。

苦手な用語は「正答率 70% 未満」または「直近が不正解」で判定します。組み合わせ問題は各用語の正誤を個別に記録し、問題全体は全組正解で正解とします。入力での誤字推測や意味の類似による自動採点は行いません。

確定した仕様は [docs/requirements.md](docs/requirements.md) に記録しています。
