# 応用情報技術者試験 用語テストアプリ

ユーザーとの対話で要件を決めながら、JavaScript / TypeScript の Web アプリとして開発する。

## 確定した要件

- 対象: 自分用。ログインは不要。
- 題材: https://www.ap-siken.com/keyword/ の用語集にある用語。
- 出題形式: 四択、○×、用語入力、穴埋め、組み合わせ。
- 学習の進め方: 問題数を固定せず、1 問ずつ継続して学習する。
- 出題設定: 分野・出題形式を選択できる。全体からランダムに出題することもできる。
- 回答後: 毎問、正解と解説を表示し、ユーザーが自分で次の問題へ進む。
- 学習記録: 同じ端末・同じブラウザに、回答履歴と正答率を保存する。
- 復習: 間違えた用語や苦手な用語を優先して出題する。
- 対応端末: スマートフォンを中心に設計し、パソコンでも利用できる。
- 初期収録範囲: 最初のバージョンから、指定された用語集の全用語を対象にする。代表的な用語だけの版を完成版とは扱わない。
- 用語入力の採点: 英字の大小、全半角、前後の空白を正規化し、登録された略称・別名も正解として扱う。意味の推測による採点や、任意の誤字の自動許容は採用しない。

- 見た目: 白を基調とし、青・緑を使ったすっきりした学習アプリ。
- 穴埋め問題: 説明文の空欄に入る用語を選択肢から選ぶ。
- 組み合わせ問題: 用語を対応する説明の枠へドラッグして配置する。スマートフォンではタッチドラッグに対応する。
- 組み合わせの初期仕様: 1 問 3 組。操作補助としてタップ選択・配置にも対応する。

## 資料の確認状況

- 用語集への接続を確認し、シラバス 7.2 の全 23 分野・96 小分類を取得した。
- 全掲載数は 5,488 件。同じ用語が複数の分野・小分類に現れるため、識別子で重複をまとめると 4,921 語になる。
- すべての掲載分を収録し、重複した用語の所属分野・小分類・登録英語名を保持する。
- `data/source-inventory.json` に取得ページ・掲載数・用語識別子・本文ハッシュを保存し、`npm run data:verify` でアプリの収録一覧と照合する。
- 元サイトは説明に生成 AI を使用していると明記している。アプリでは短い学習用説明を用い、各用語の出典ページへリンクする。学習用説明の内容を人手で全件校正したものではない。

## 開発の現状

- React / TypeScript / Vite で実装。
- ホーム、学習設定、5 形式の出題・解説、用語検索、学習記録の画面を用意する。
- 記録はブラウザの localStorage に保存する。ログイン・サーバーへの記録送信・端末間同期は行わない。
- 苦手な用語の判定: 正答率が 70% 未満、または直近の回答が不正解。通常学習でも苦手な用語の抽選比率を高くし、苦手な用語を中心とした復習も選べる。組み合わせ問題の補助用語は同じ出題範囲から選ぶ。
- 通常の出題では、候補が十分にある限り直近 3 語の連続出題を避ける。
- 回答履歴の保存失敗・破損は通知する。破損した保存内容を自動上書きしない。
- 具体的な検証コマンドと結果は README とテストに記載する。
